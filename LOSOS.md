# LOSOS.md

LosOS is a fast, lightweight, terminal-first AI-native development environment:
multi-tab terminals with a native PTY backend, an integrated code editor, file
explorer, source control, web preview, and an agentic AI system that works with your
own API keys or fully local models.

This file is the living architecture reference and the source of truth for
contributors. If a guide in `docs/` conflicts with this file, this file wins.

Long-form contributor guides live in [docs/README.md](docs/README.md).
